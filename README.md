# 北极星 · Polaris

以目标为参照，走好每一步。

北极星是一款面向基金与股票的投资计划测算、执行记录与收益跟踪工具。用户设置计划的执行周期和每个 step 的目标参数，软件结合当前价格及实际持仓，计算下一步的投入建议，并展示计划进度与收益变化。

## 当前阶段

项目已确定名称与初步产品方向，正在细化需求。技术栈、计算规则和页面方案尚未确定，后续逐步补充。

- 中文名称：北极星
- 英文代号：Polaris
- 仓库名称：`polaris`

## 核心流程

1. 创建一条投资计划，绑定指定的基金或股票。
2. 设置执行频率，以及每个 step 的基准金额或目标参数。
3. 根据当前净值或股价、持仓与目标路径，计算下一步需要投入的金额。
4. 记录实际执行结果，跟踪累计投入、当前市值、计划进度和收益变化。

策略暂按用户提到的“市值恒定法”方向理解，具体目标市值路径及投入规则待确认。
