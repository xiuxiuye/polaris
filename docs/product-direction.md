# 北极星：产品方向

记录日期：2026-10-28（Asia/Shanghai）。

本文记录已沟通的方向与待确认事项，用于后续需求细化。

## 已明确的方向

- 中文名称为“北极星”，英文代号与仓库名为 `polaris`。
- 项目从零开始，使用独立仓库。
- 产品专注于基金、股票的投资计划与收益跟踪。
- 用户创建一条记录或计划，并绑定一个指定投资标的。
- 用户可设置每个 step 的基准金额以及执行频率。
- 软件结合标的最新净值或股价、实际持仓，计算下一步需要投入多少。
- 软件能够展示当前收益，并保留后续补充需求的空间。
- “北极星”的主要意象是目标与参照：先明确目标路径，再依据实际情况调整每一步。

## 当前理解，待确认

用户提到的策略暂理解为“市值恒定法 / 价值平均法”方向：每期有预设的目标市值，软件根据目标与实际市值的差额进行测算。

这是一项工作假设。用户尚未确认具体公式、目标增长方式及资金处理规则，实施前需要用具体案例对齐。

## 后续需要细化

1. **step 金额的含义**：是目标市值增量、基准投入额，还是其他参数；是否支持自定义目标路径。
2. **投入建议的边界**：实际市值超过目标、资金不足、漏投或暂停时如何计算下一步。
3. **持仓与执行记录**：期初持仓如何录入，实际成交份额、价格、费用及分红如何记录。
4. **周期与价格**：支持哪些频率，如何处理交易日、时区、基金净值滞后及数据缺失。
5. **收益口径**：累计投入、当前市值、收益金额及收益率分别如何计算与展示。
6. **产品与技术方案**：首期支持的标的范围、运行平台、行情来源、数据存储和技术栈。

## 下一步

后续开始开发时，先用一组实际的投资计划与持仓示例明确计算过程，再确定首期范围、数据模型和技术方案。
